PETUNJUK MENGGUNAKAN BOARD FISIK:
  1. Flash sketch C++ ke Wemos D1 Mini / ESP32.
  2. Tekan tombol merah (tahan 2 detik) untuk menyalakan layar OLED.
  3. Ketik 4 simbol challenge (△, ○, X, □) menggunakan 4 tombol fisik.
  4. Layar OLED akan langsung menampilkan 12 simbol respon pemecah sandi.

SKEMA ALUR SISTEM 3 DEVICE (ENKRIPSIH)

Architecture Blueprint & Node Topology
KEYBCA PROTOCOL

DEVICE 1: LAPTOP KOMANDAN

Web Portal Pengirim
  • Login biometrik verifikasi wajah OpenCV
  • Input pesan perintah intelijen
  • Generate 4 simbol challenge (△ ○ X □ / TCXS)
  • Enkripsi payload dengan PBKDF2 + AES-GCM
  • Transmisikan paket terenkripsi ke server

DEVICE 2: TOKEN KEYBCA (WEMOS / ESP32)

Pemecah Sandi Kripto
  • Chip hardware menyimpan SECRET_KEY
  • Input 4 simbol via tombol fisik
  • Layar OLED menampilkan bentuk grafis simbol
  • Kalkulasi HMAC-SHA256 secara instan (<2ms)
  • Menghasilkan 12 simbol respon token pemecah kode

DEVICE 3: RECEIVER BAWAHAN

Terminal Tampilan Intelijen
  • Menerima notifikasi transmisi masuk real-time
  • Menampilkan status terkunci & 4 simbol challenge
  • Menerima input 12 simbol respon dari KeyBCA
  • Dekripsi AES-GCM dan render pesan taktis
  • Fitur penghancuran pesan (Self-Destruct)
