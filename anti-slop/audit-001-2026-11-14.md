# Audit 001

## Temuan

### 1. HIGH: Klaim enkripsi end-to-end tidak sesuai alur pesan aktif

**Lokasi:** [landing.html](../frontend/landing.html), [index.html](../frontend/index.html), [app.js](../frontend/js/app.js), [tour.js](../frontend/js/tour.js)

Halaman menyebut enkripsi berjalan di browser, server tidak pernah melihat isi pesan, dan semua kunci hanya berada di browser. Namun alur kirim aktif mengirim `plaintext` ke endpoint backend `/api/messages/encrypt-agent`; backend mengenkripsi pesan ([main.py](../backend/main.py#L1137)). Endpoint `/api/messages/decrypt` juga mendekripsi pesan di backend ([main.py](../backend/main.py#L1257)). Karena itu, klaim tersebut dapat membuat pengguna salah memahami siapa yang dapat mengakses isi pesan.

**Perbaikan yang disarankan:** ganti dengan keterangan yang menyatakan database menyimpan ciphertext, sementara backend memproses plaintext saat pengiriman dan pembukaan pesan. Hindari istilah “end-to-end” dan klaim bahwa server tidak dapat membaca pesan.
