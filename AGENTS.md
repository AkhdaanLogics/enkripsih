## Antislop — load otomatis setiap sesi frontend

Setiap kali mengerjakan atau mengedit file di `frontend/` (HTML, CSS, JS),
load **seluruh** skill antislop berikut tanpa perlu diminta:

- `antislop`
- `antislop-ui`
- `antislop-code`
- `antislop-human`
- `antislop-copywriting`
- `antislop-layoutmobile`

Semua skill terpasang di `.agents/skills/` (sumber: `miqdadbadjuber/anti-slop`).
Aturan inti: desain harus terasa dibuat desainer, bukan dihasilkan AI.
